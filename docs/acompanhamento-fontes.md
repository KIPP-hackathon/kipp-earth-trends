# Acompanhamento das fontes

O inventário e as definições das fontes são mantidos em [fontes-transient-dados.csv](fontes-transient-dados.csv).

Os recursos de ingestão são definidos em `databricks/resources/data-extraction.jobs.yml`. Consulte `databricks bundle summary` para os jobs publicados e o histórico de execução no workspace para acompanhar as cargas.

As instruções operacionais estão no [guia de deploy](databricks-bundle.md) e no [guia de descrições](descricao-tabelas-fontes.md).
