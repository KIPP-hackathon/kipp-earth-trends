# Explore first, save discoveries

User-approved scope: explore freely or start from an editable event preset; name an investigation only when saving it. No login. Store compact configuration and notes locally, share configuration in a URL fragment, export/import JSON. Reopening requests current source data, not a frozen scientific result. Explain browser-local persistence and lack of cross-device sync.

Use localStorage for this bounded configuration-only v1 behind a focused persistence module. IndexedDB is a possible later adapter for offline datasets, not needed for saving filters. Never persist provider credentials, device coordinates or an assistant conversation. Save exactly the active workspace: variables, area geometry metadata, monthly dates, camera, color range and optional curated event ID. Imported/shared input is untrusted; bounded validation and actual catalog validation precede atomic restore. Missing data yields an actionable error without silent substitution.

UX: compact date period controls, current month beside playback, searchable variable catalog, country selection and drawing, true clear-to-global, no large enclosing globe border. Keep global fields and regional/global charts, independent Explore/Compare state, smooth camera, accessible controls and reduced motion. Country borders remain generalized; stats are explicitly bbox-based. Selecting an event applies its region and supported event period; related-variable suggestions explain relevance and distinguish catalog overlap from actual regional coverage. Manual area changes clear incompatible event context. Analysis exposes existing precomputed methods only for exact supported variable/region/period, never borrowing another region's significance.

Approaches considered: cosmetic-only compaction is quickest but leaves the investigation flow incomplete; a mandatory wizard conflicts with free exploration; enhance existing tabs with editable event context and save-on-demand (chosen in conversation). Keep English in newly authored primary UI, source metadata as delivered. Do not add auth, large datasets to browser storage, new dependencies or claims of causal event detection. Existing tests/builds and focused smoke/browser checks suffice; user waived new test suites for hackathon speed. Preserve unrelated architecture documents and AI-register edits.
