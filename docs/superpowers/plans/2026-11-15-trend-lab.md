# Trend Lab Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. Track steps below.

**Goal:** Add an interactive English Trend Lab with real regional series and runtime linear regression.

**Architecture:** Isolated workspace reusing RealGlobe, SearchPicker and loadSeries. A pure monthly regression module feeds a standalone SVG chart and projection controls.

**Tech Stack:** Existing React/TypeScript, SVG, Vitest, Node.js 24; no new packages.

**Spec:** `docs/superpowers/specs/2026-11-15-trend-lab-design.md`

## Global Constraints

- Preserve existing uncommitted edits; work in the current feature checkout without Git mutations or publication.
- English UI, real series only, explicit rectangular aggregation and source provenance.
- OLS on calendar months, 95% Student-t slope interval, at least three valid months.
- No significance claims for categorical, insufficient or degenerate data; state seasonality/autocorrelation limitations.
- Independent filters and camera; do not give the assistant another workspace's context in Trend Lab.

## Review Focus

- Gaps/nulls must not become zero or compressed month indices (regression tests).
- Reference regression intervals must match known Student-t values (regression tests).
- Edited filters must never relabel a submitted result (browser check).
- Categorical/unavailable variables and no regional coverage must not produce a fit (UI and tests).
- Hidden tabs, mobile widths and endpoint controls must preserve state and remain operable (browser check).
