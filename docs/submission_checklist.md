## Status key

- **Evidence found** — a source or artifact currently supports the statement.
- **Partial** — some supporting evidence exists, but a submission-level action or review remains.
- **Pending** — no adequate evidence found in the repository or reviewed deployment notes.
- **Confirm** — rule or project fact must be checked with the official portal, Local Lead, or team.
